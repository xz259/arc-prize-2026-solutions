# Launching the server

On the pods these files sit in `/workspace/kvring_dev/fin74/s2/`, beside the [stage-2 package](../stage2/); the chat template and `stage0-reference/` come from two older run directories under `/workspace/arc3-inference/runs/`.

| File | Role |
|---|---|
| `launch_scaling_s2i.py` | The pod launcher. It checks the overlay against its manifest, turns the profile's environment into vLLM's command line and environment (KV pool size, CUDA graph sizes, the drafter, the bootstrap chain with stage 2 as its outermost link) and starts, checks or stops one server instance. |
| `k_launch_scaling_s2i.py` | The Kaggle launcher: the same file with every check that would stop a launch turned into a log line, because a blocked start scores zero. It is generated by [`mk_klaunch.py`](../../arc3/kaggle/build/mk_klaunch.py). |
| `k_runtime_python.sh` | The Kaggle copy of [`../base/runtime_python.sh`](../base/runtime_python.sh). |
| `prolong_chat_template_v529.jinja` | The chat template the server runs with. |
| `draft_vocab_32k.json` | The 32,000 token ids that the drafter scores (stage-2 part `drafthead`). The file is `configs/draft_vocab_32k.json` from the public Kaggle dataset `lordhansolo/taaf-kaggle-source`, a milestone-2 solution, unchanged. |
| `nll_panel_i.sh`, `probe_instance.py`, `stage0-reference/` | The NLL fingerprint: the probe scores a fixed set of tokens from recorded conversations on the running server, and the mean NLL is compared with the value recorded for the profile. A match to the last digit shows that a launch computes the same numbers as the reference launch. |
| `nll-panels/*/DERIVED.json` | Records of the scoring set as adapted to each checkpoint folder. The set itself (`panel.json`, recorded gameplay) is not in the repository. |

The profiles that the launchers start are defined in [`../../arc3/kaggle/kaggle_defs/KDEF.json`](../../arc3/kaggle/kaggle_defs/KDEF.json); the driver that renders them is [`../../arc3/kaggle/kaggle_run.py`](../../arc3/kaggle/kaggle_run.py).
